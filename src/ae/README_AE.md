# 拔钉救人核玩工具 · AE 工程导出说明

1. 解压 zip，After Effects（2020+）→ 文件 → 脚本 → 运行脚本文件 → 选 `build_ae_project.jsx`（需与 `timeline.json`、`assets/`、`audio/` 同目录）。
2. 脚本会新建工程：文件夹「拔钉救人_AE工程」，主合成「主合成_拔钉救人」（尺寸 = 导出时画布的可视区域，帧率见 timeline.json）。
3. 图层（从下到上）：背景（砖墙 / 管道 / 房间拱门）→ 小人（惊恐 / 推杆 / 被压三种姿势分段，抖动 = 位置关键帧）→ 支撑杆 → 压板（旋转关键帧，锚点在右侧铰链）→ 铰链与铁钉 → 每颗石头一个图层（位置 / 旋转 / 缩放关键帧，可在面板里关闭）→ 每块木板一个图层 → 每颗钉子一个图层 → 目标盒（每个盒子一段，缩放 = 弹入 / 缩小）→ 盒中钉 → 填满闪光（相加混合）→ 飞行钉 → 烟雾 → 标题 → 倒计时（每秒一个图层）→ 失败模糊（调整图层 + 高斯模糊关键帧）→ FAIL 徽章 → 免责声明 → 结束页 → 点击波纹 → 手指。
4. 音频：`audio/mix.wav` 混合音轨 + 预合成「音效_逐事件」（拔钉 / 入孔 / 填满 / 木板 / 滴答 / 压塌 / 失败各一层），主合成上有对应标记。

已知限制（如实说明）：
- 倒计时进度环在 AE 里每秒跳一格（每个数字一张静态图），页面上是连续减少。
- 小人在 AE 里只有三种静态姿势（页面上推杆时手臂会跟随支撑杆、头会微动），切换为硬切。
- 失败时的偏蓝压暗没有单独导出（只有高斯模糊调整图层）。
- 填满闪光为单张素材缩放 + 透明度，页面上是逐帧绘制的放射线与火花。
- 石头图层数量多（几百层），导入 AE 会比较慢；可在面板「石头图层」里选择不导出。
